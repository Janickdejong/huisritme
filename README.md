# Huisritme

Een rustige huishoudapp met een dagritme, kamers, eten, was en een tuintje als beloning. Alles staat alleen op je eigen telefoon; geen account nodig.

- Download de nieuwste `Huisritme.apk` via **Releases** en installeer hem.
- Nieuwe versie maken: zet een nieuwe `huisritme.html` in de repo. GitHub bouwt dan vanzelf een nieuwe APK.
